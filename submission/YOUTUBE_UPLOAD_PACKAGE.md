## Description

Codex Ascend turns one real objective into a living expedition shared by a human and an AI agent.

Instead of hiding agent work in a chat transcript or decorating a checklist, Ascend projects authoritative mission state into a persistent mountain: camps are outcomes, fog is uncertainty, blockers fracture the route, new scope reveals new terrain, and the Summit activates only after evidence-backed verification.

The deployed experience exposes 18 native WebMCP tools for mission inspection, execution, blockers, evidence, human decisions, scope expansion, and completion. The agent and website use the same deterministic command engine and event journal.

The central interaction is deliberately bidirectional:

1. The agent reports a blocker and proposes two routes.
2. The website renders the decision at the affected mountain geography.
3. The human chooses Repair persistence.
4. The agent reads that structured decision through `inspect_human_decision` and continues.

There is intentionally no agent tool that can make the consequential human decision.
